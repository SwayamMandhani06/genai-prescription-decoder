# AURA-Rx Confidence Estimation & Calibration Design Specification

**Module:** Phase 8 — Confidence Estimation & Calibration  
**Document Version:** 1.0.0  
**Date:** 2026-09-27  
**Status:** IMPLEMENTED  
**System:** Explainable Multimodal AI for Handwritten Prescription Understanding (AURA-Rx)  

---

## 1. System Objective & Core Philosophy

The primary purpose of Phase 8 is to construct a scientifically sound confidence estimation and calibration framework for outpatient prescription interpretations.

### Fundamental Scientific Tenets
1. **Raw Model Signal != Probability:** An uncalibrated soft score or softmax output generated by a multimodal neural network (e.g., 0.87) is not an empirical probability of correctness.
2. **Retrieval Similarity != Probability:** An orthographic or lexical similarity score (1.0) between an extracted token and an approved formulary database record denotes reference alignment, not handwriting interpretation correctness.
3. **Decoupled Visual Extraction vs. Reference Grounding:** Strong reference correspondence from retrieval must *never* artificially erase visual uncertainty originating from degraded handwriting.
4. **Dosage Visual Invariant:** Observed dosage strength is strictly safety-critical. Reference data containing a matching dosage formulation (e.g., 500 mg) is supporting evidence of formulation plausibility, but visual confidence in dosage must remain strictly grounded in handwriting stroke evidence. Observed dosage values are strictly immutable and never rewritten.
5. **No Premature Abstention (Phase 9 Boundary):** Phase 8 produces calibrated confidence representations and uncertainty metadata. It does *not* enforce selective abstention thresholds or policies (e.g., `if confidence < 0.80 -> abstain`). That policy belongs strictly to Phase 9.

## 2. Confidence Sources & Semantics

Confidence signals originate from three distinct and decoupled pipeline sources:

### A. Multimodal Visual Extraction Signals (Phase 6)
- **Visual Confidence Score:** Raw continuous model signal in [0.0, 1.0].
- **Field Status:** Categorical visual clarity assessment (`confident`, `uncertain`, `flagged`, `abstained`).
- **Extraction State:** Structural presence (`extracted`, `ambiguous`, `missing`, `hallucination_guarded`).
- **Presence Flag:** `present` vs `absent`.
- **Candidate Presence:** Number of competing handwriting stroke hypotheses.

### B. Formulary Reference Validation Signals (Phase 7)
- **Validation Status:** Regulatory standing (`validated`, `uncertain`, `not_validated`).
- **Match Method:** Alignment mechanism (`exact_normalized_name`, `exact_alias`, `exact_ingredient`, `token_overlap`, `lexical_similarity`).
- **Retrieval Score:** Deterministic similarity score in [0.0, 1.0].
- **Candidate Margin:** Score differential between rank-1 and rank-2 reference candidates.
- **Formulation Consistency:** Dosage agreement (`consistent`, `mismatch`, `not_applicable`).

### C. Ground-Truth Empirical Outcomes (Phase 3 & Phase 12)
- **Binary Field Correctness:** Dataset-provided ground-truth annotations ($y_i \in \{0, 1\}$).
- **Identity Correctness:** Medicine entity correctness vs dataset ground-truth annotated prescription fields.
- **Dosage Strength Correctness:** Strict visual fidelity of dosage numerical values against ground truth.

## 3. Raw Score vs. Calibrated Confidence

To prevent false confidence and deceptive presentation, the system maintains strict architectural separation:

```json
{
  "raw_signal": {
    "source": "multimodal_gemini-3.8-flash",
    "raw_value": 0.94,
    "signal_type": "model_visual_stroke_confidence",
    "model_version": "gemini-3.8-flash",
    "config_version": "confidence_calibration_v1"
  },
  "calibrated_confidence": {
    "value": null,
    "calibration_method": "platt_scaling",
    "calibration_version": "1.0.0",
    "calibration_dataset_version": "1.0.0",
    "calibration_status": "insufficient_data"
  }
}
```

### State Semantics (`calibration_status`)
- `calibrated`: Calibrated using empirical model fitted on >= 15 validated samples.
- `insufficient_data`: Data cohort is smaller than minimal sample threshold (N < 15). Calibrated value remains null to prevent misleading estimation.
- `uncalibrated`: Raw model score exists, but calibration model has not been executed.
- `not_available`: Field was missing or unobserved; no confidence score exists.

## 4. Field-Level Granularity & Multi-Medicine Independence

Prescription understanding requires field-level decomposition. Aggregating an entire prescription into a single scalar confidence score obscures safety-critical risks.

### Independent Field Assessments
Each medication item contains separate confidence assessments for:
1. `medicine_name`: Identity extraction confidence decoupled from formulary match.
2. `dosage`: Visually grounded strength confidence with reference consistency audit.
3. `frequency`: Posology schedule extraction confidence.
4. `duration`: Course duration extraction confidence.
5. `abbreviations`: Medical Latin / shorthand interpretation confidence.

### Multi-Medicine Non-Inflation Invariant
In multi-line prescriptions:
High confidence in extracting *Paracetamol 500mg* does **not** inflate confidence in an adjacent ambiguous *Amox...* line item.

## 5. Conflict Detection & Preservation

When visual extraction and formulary retrieval yield divergent evidence, the system preserves the conflict rather than averaging scores:

| Scenario | Visual Confidence | Retrieval Score | Detected Conflict Flag | Action Taken |
| :--- | :---: | :---: | :--- | :--- |
| Truncated cursive stroke matching full formulary title | 0.50 (Uncertain) | 0.98 (Overlap) | `AMBIGUOUS_CURSIVE_STROKE`, `RETRIEVAL_DISCREPANCY` | Expose `conflict_detected = True` and retain conflict metadata (Phase 8 does not execute human verification routing). |
| Prescribed dosage differs from approved commercial strength | 0.95 (Confident) | 1.00 (Formulary) | `DOSAGE_FORMULATION_MISMATCH` | Flag mismatch; preserve observed dosage; do not rewrite. |
| Multiple close lexical candidates | 0.50 (Ambiguous) | 0.85 vs 0.82 | `MULTIPLE_REFERENCE_CANDIDATES` | Flag candidate ambiguity; retain candidate list. |

## 6. Calibration Methodology & Mathematical Formulations

### A. Platt Scaling (Logistic Calibration)
Fits a univariate logistic sigmoid over raw scores s:
P(Y = 1 | s) = sigma(A * s + B) = 1 / (1 + exp(-(A * s + B)))
Parameters A, B in R are estimated via binary cross-entropy minimization with L2 regularization to prevent overfitting on small validation cohorts.

### B. Isotonic Regression
Fits a non-decreasing piecewise constant function using the Pair-Adjacent Violators (PAV) algorithm:
min sum_{i=1}^n (y_i - y_hat_i)^2 subject to y_hat_1 <= ... <= y_hat_n
Suitable when relationship between raw score and empirical correctness is strictly monotonic but non-logistic.

### C. Temperature Scaling
Rescales unnormalized logit inputs z:
p_hat = sigma(z / T), T > 0
Preserves ranking order while dampening overconfidence (T > 1) or sharpening underconfidence (T < 1).

## 7. Calibration Evaluation Metrics

### 1. Expected Calibration Error (ECE)
Partitions predictions into M equal-width confidence intervals B_m in [0, 1]:
ECE = sum_{m=1}^M (|B_m| / N) * |acc(B_m) - conf(B_m)|

### 2. Maximum Calibration Error (MCE)
Measures worst-case bin deviation:
MCE = max_{m in {1, ..., M}} |acc(B_m) - conf(B_m)|

### 3. Brier Score
Strictly proper scoring rule assessing overall mean squared probabilistic error:
Brier = (1 / N) * sum_{i=1}^N (p_hat_i - y_i)^2

### 4. Negative Log-Likelihood (NLL)
Cross-entropy loss computed only when valid probabilistic predictions exist:
NLL = -(1 / N) * sum_{i=1}^N [y_i * log(p_hat_i) + (1 - y_i) * log(1 - p_hat_i)]

## 8. Statistical Integrity & Population Separation

The system maintains a strict, unbreached distinction between development samples and synthetic calibration verification data:

### A. Real Curated Dataset (N=7 AURA-Rx Sample Set)
- **Population:** 7 de-identified outpatient handwritten prescription documents.
- **Purpose:** Engineering integration, pipeline connectivity, and UI state calibration.
- **Limitation:** Statistically insufficient ($N=7 < 15$) for fitting clinical calibration parameters.
- **System Behavior:** `calibration_status = "insufficient_data"`, `calibrated_confidence = None`.

### B. Synthetic Calibration-Method Verification Cohort (N=15)
- **Population:** 15 deterministic synthetic test samples (`dataset_type = "synthetic_verification"`).
- **Purpose:** Verification of calibrator convergence, PAV algorithm correctness, and ECE/MCE computation.
- **Scientific Limitation:** Strictly labeled `clinical_evidence = False`. Under no circumstances are synthetic verification metrics described as empirical clinical calibration performance.
